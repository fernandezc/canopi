- **Exit numbers** read from the ratchet files (contracts §12). A ratchet only shrinks. A number the phase misses goes to the user with its reason, never into a raised baseline.

This plan and its contracts file are deleted; the ledger stays. 2.1.0 ships updater-signed (Windows code-signed if the SignPath grant exists) and deploys Web (2.1-Q5); then one release per roadmap item.

**User hears.** Any scenario still over its bound, with a costed redesign rather than a patch, and the follow-up beads.
